## 今回の見どころ

### ABI の教科書ができた (#11)

`doc/textbook/` に、規約の一覧と理由、語の表、C の書き手向けの説明、移行の手引き、配布の決まりなどを 7 章でまとめた。C の例 3 本（最小の SHIORI、版ごとのテーブル、最小のホスト）も付けた。ルートの README には全体図と最小の例を載せ、教科書と docs.rs へ導く。

### 応答はホストが作り、ホストが解放する (#11)

応答の `ShioriBytes` は常にホストが作り、SHIORI は `ShioriHostApi` に足した `copy_from_slice` で写す。`release` は常にホストの関数なので、unload の後でも、どのスレッドからでも呼べる。

### ベースウェア無しで試せるホスト (#11)

`shiori4_host` の example `shiori4-testhost` で、SHIORI を 1 往復させられる。終了の状態で結果を返すので、他のリポジトリの CI から使える。

### 動きが変わる点

- `ShioriHostApi` の末尾に `copy_from_slice` を足した。関数の形は変わらないが、前の版と二進互換でない。新しい SHIORI は、`copy_from_slice` を持たない古いホストでは load に失敗する。SHIORI もホストも、この版で作り直す。 (#11)
- v3 互換モードの load にも、`copy_from_slice` だけを持つテーブルを渡す。`copy_from_slice` の無いテーブルでは load が失敗する。 (#11)
- Rust の `ShioriHostApi` の `request`・`post`・`log` の欄を `Option` にした（二進の形は C と同じ）。 (#11)
